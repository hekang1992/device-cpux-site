Common questions

Why are some readings unavailable?

Some information is restricted by iOS interfaces, device hardware, or permissions. An unavailable reading does not establish a fault. Check permissions and try the feature on a physical device.

How do I enable camera, microphone, location, or motion permissions?

Open the relevant test and follow the system prompt. If you previously denied access, find Device CpuX in iOS Settings or change the permission under Privacy & Security.

How can I delete test history?

Open app Settings and use the clear test data action in the data section. This removes recent test records and current network test results without resetting language, appearance, or widget snapshots.

Why does the widget show an older reading?

Widgets display the most recent snapshot saved by the main app. iOS controls refresh timing. Open the main app to update the snapshot; the widget does not continuously monitor in the background.

Do network tests use mobile data?

Yes. Tests request your selected HTTPS URL only when you start them, and may use mobile data on cellular connections. A separate session request occurs once per app process launch; see the privacy policy.

Can diagnostics be used as a repair assessment?

The app displays public system information and helps you check features. Permissions, conditions, and system limitations affect results. For persistent faults, contact Apple or an authorized service provider for a professional assessment.
