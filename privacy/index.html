隐私政策

本政策说明 Device CpuX 读取什么、在本机保存什么，以及联网与分享时发生什么。

生效日期 / 最近更新: 2026-10-29 · Device CpuX

无需账户。设备读数与诊断结果在本机处理；本地历史、小组件缓存、启动请求及用户主动分享的处理方式详见下文。

1. 适用范围与开发者

本政策适用于由 zhangzheng 提供的 Device CpuX iPhone 应用、配套桌面小组件及本官网。隐私相关问题请发送至 18260061607@163.com。

2. 设备与诊断数据

应用使用 iOS 公开接口，在本机读取和展示机型、系统版本、处理器、图形能力、电量、内存、存储、温度状态及网络连接信息。这些设备读数与检测结果不会由应用自动上传至开发者服务器。应用无需创建账户，不集成广告 SDK 或用于跨应用追踪的分析 SDK，仅在你同意 iOS 系统授权后读取广告标识符（IDFA），用于在应用隐私页面显示及检查其可用性；不读取 IMEI 或设备序列号。IDFA 的处理和选择详见第 4.1 节。部分规格来自 DeviceKit 的机型资料，可能与实时系统状态不同。

3. 本地保存、保留与清除

  • 偏好：应用在本机保存语言和外观设置。
  • 近期测试：在本机保存检测结果计数、网络测试主机名与性能结果、触控覆盖结果及测试时间。每类最多保留最近 12 条，更新后较旧记录会被替换。
  • 小组件：主应用通过本机 App Group 与小组件共享最近一次设备快照，包括机型、系统版本、电量、存储、物理内存、充电与温度状态、语言及更新时间。后续快照会覆盖前一次快照。
  • 传感器：实时定位、运动、气压、计步和麦克风采样用于当前功能，应用不保存原始传感器轨迹、录音或相机影像。
  • 清除：在应用“设置”的数据区域使用清除测试数据功能，可移除近期测试记录及当前网络测试结果；该操作不会同时清除语言、外观或小组件快照。删除应用可移除其应用容器数据；小组件共享数据的清理由 iOS 管理。本地应用数据也可能纳入由你控制的系统备份。

4. 权限与传感器

权限或能力使用目的与处理方式
定位与指南针仅申请“使用 App 期间”定位权限，不申请“始终允许”。只有你主动使用定位、GPS 或指南针功能时才获取当前位置，用于显示坐标、精度、方向与海拔，并在系统允许时显示 Wi-Fi 信息。支持单次定位和当前页面内的实时测试；单次获取完成、停止测试、离开页面或进入后台后停止相应定位。不进行后台定位，不保存位置轨迹，也不上传位置。
麦克风实时检测输入音量与波形，在内存中处理，不保存录音。
相机与闪光灯检查相机能力、预览或闪光灯。不自动保存或上传照片、视频。
运动与健身按需读取加速度、陀螺仪、气压或当前会话计步信息。
蓝牙与本地网络检查蓝牙可用状态，或执行你主动发起的本地网络诊断。

你可以在 iOS“设置”中拒绝或撤回授权；相关功能可能因此不可用，其他无需该权限的功能仍可使用。实时传感器测试在退出相应页面或进入后台时停止。

4.1. 广告标识符（IDFA）与系统授权

应用在启动页结束、进入前台可交互状态后，尝试通过 AppTrackingTransparency 请求系统授权。只有 iOS 状态为“允许”时才通过系统接口读取 IDFA，并在应用“权限与隐私”页显示，供你检查标识符是否可用。当前版本只在运行期间的内存中处理 IDFA，不保存到本地文件或测试历史，不附加到启动请求、网络测试或小组件快照，不上传给开发者、广告平台或其他第三方，也不用于跨 App 或网站跟踪。拒绝、撤回或被系统限制时不读取 IDFA，不使用其他标识符替代或绕过授权；诊断等其他功能仍可使用。弹窗是否出现由 iOS 控制：已作出选择、关闭系统“允许 App 请求跟踪”或受到系统限制时，可能不会弹出或重复弹出。你可在 iOS“设置 → 隐私与安全性 → 跟踪”中管理授权；后续进入前台时应用会重新读取授权状态，撤回后停止读取并清除内存中的 IDFA。

5. 启动请求、网络测试与 Cookie

启动请求：每次应用进程启动后，会向应用服务端发送一次网络数据请求，用于初始化会话和获取会话安全信息。应用不在该请求中附加设备读数、定位、诊断结果或广告标识符。通信本身会使接口及网络服务商接收到 IP 地址、请求时间、请求头等连接元数据；系统网络会话可能接收、保存及再次发送服务端返回的 Cookie。这些元数据与会话 Cookie 不等同于诊断数据上传。接口服务端可能为提供服务、安全和故障排查而处理访问日志；其具体日志字段、保留期限及 Cookie 有效期取决于服务端配置，需通过开发者联系渠道确认。

主动网络测试：仅在你点击开始后，请求你选定的 HTTPS 地址，默认地址为 Apple 官网。目标网站会按其自身政策处理网络请求、IP 地址等元数据；测速会使用网络流量。应用使用临时网络会话执行此测试。

6. 分享、支持邮件与第三方

应用不会自动出售或向广告商分享设备读数、传感器数据或测试历史。你主动使用系统分享功能导出摘要时，所选接收方将收到你分享的内容，其后续处理适用接收方的政策。你主动联系支持时，开发者会使用邮件地址、问题描述和你提供的附件处理请求；请勿发送密码、身份证件或无关个人信息。支持邮件的保留以解决请求及必要后续沟通为目的；可通过联系邮箱提出删除请求。DeviceKit 用于设备型号与规格查询，Alamofire 用于联网请求；SDK 的存在并不表示会向其作者上传诊断数据。

7. 官网访问

本官网为静态页面，不设置分析 Cookie、不加载广告或第三方统计脚本，也不读取应用内的诊断历史。提供网站的托管或网络服务商仍会接收 IP 地址、浏览器请求头及访问时间等连接元数据，并可能按其自身政策保存访问和安全日志。本网站的托管服务商为 GitHub Pages (GitHub, Inc.)。 官网没有注册、评论或文件上传功能。

8. 你的选择与隐私请求

你可以在系统设置中管理权限，在应用内清除近期测试数据，或停止使用及删除应用。应用没有用户账户，无需申请账户注销。开发者无法从服务器调取仅保存在你设备上的测试记录。对支持邮件或可识别到你的服务端信息，你可通过联系邮箱提出访问、更正或删除等请求；开发者会核实请求并依据适用要求处理。

9. 儿童、存储位置与安全

应用不以收集儿童个人信息为目的，也不要求提供出生日期。发现儿童通过支持渠道提供了个人信息时，可联系开发者处理。诊断及传感器数据在本机处理；你主动使用的邮件、分享服务、网站托管和启动接口可能在其服务覆盖地区处理联网信息。网络请求使用 HTTPS；系统权限和应用沙盒提供本机访问控制，但任何系统都无法保证绝对安全。

10. 政策变更与联系

应用的数据处理方式发生变化时，本页面会相应更新并显示生效日期；如有需要，会通过应用或其他适当方式告知。关于本政策或隐私问题，请联系 zhangzheng：18260061607@163.com。
